# Flood Eagle

Flood Eagle provides live weather, recent rainfall, a seven-day flood forecast, a map and practical safety advice for places across India.

## Run on Windows

1. Extract this ZIP file.
2. Double-click **Add Flood Eagle to Desktop.bat** once to create the desktop shortcut.
3. Open **Flood Eagle** from the desktop.
4. Keep the extracted folder on your computer.

You can also double-click **Start Flood Eagle.bat** to start it directly and **Stop Flood Eagle.bat** to stop it. Internet access is needed for live weather and map information.

## Flood intelligence features

- Flood probability for each forecast day
- Weather pattern groups: Dry / Clear, Showery and Heavy Rain
- Rainfall direction and rate of change over the past seven days
- Unusual heavy-rain alerts
- Forecast-factor influence chart
- Comparison between flood probability and the standard risk score

## Development

Requires Node.js and npm.

```sh
npm install
npm run dev
```
